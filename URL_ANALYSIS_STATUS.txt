🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════════

1. START THE APPLICATION
   cd c:\Users\abhik\projects\Xerova
   npm run dev

2. ACCESS THE DASHBOARD
   Navigate to: http://localhost:3000/dashboard/assistant/url-analysis

3. ENTER A URL
   • https://google.com (for safe URL test)
   • https://paypa1-secure-login.example.xyz (for malicious test)
   • https://amaz0n.com (for suspicious test)

4. VIEW RESULTS
   • Risk score visualization
   • Detailed findings breakdown
   • Threat intelligence data
   • Actionable recommendations

5. API USAGE (via cURL)
   curl -X POST http://localhost:3000/api/threats/url-analysis \
     -H "Content-Type: application/json" \
     -d '{"url":"https://example.com"}'
